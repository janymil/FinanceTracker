Correct Fix (Minimal, Clean — Keep Everything Else as Is)
🔧 Step 1: Go to your help.tsx, contact.tsx, etc.
Look for something like:

tsx

Edit
import { AnonymousHeader } from "@/components/anonymous-header";

export default function HelpPage() {
return (
<>
<AnonymousHeader />
<main>...</main>
</>

}
This must be changed to a version that checks the user’s auth status dynamically.

✅ Step 2: Replace Hardcoded Anonymous Layout with Conditional Header
✅ Example:
tsx
Copy
Edit
import { useUser } from "@clerk/clerk-react";
import { Header } from "@/components/header";
import { AnonymousHeader } from "@/components/anonymous-header";
import { Footer } from "@/components/footer";

export default function HelpPage() {
const { isSignedIn } = useUser();

return (
<>
{isSignedIn ? <Header /> : <AnonymousHeader />}
<main className="px-4 py-6 max-w-3xl mx-auto">
<h1>Help</h1>
<p>This is the help page...</p>
</main>
{!isSignedIn && <Footer />}
</>
);
}
✅ Works in all routes: /help, /es/help, /sk/help

✅ Respects the auth state

✅ Does not affect routing

✅ Keeps your original working design

✅ No need to wrap everything in AppLayout
