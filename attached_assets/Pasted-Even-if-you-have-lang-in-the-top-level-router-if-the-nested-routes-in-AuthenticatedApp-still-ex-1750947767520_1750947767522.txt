Even if you have /:lang/* in the top-level router, if the nested routes in AuthenticatedApp still expect absolute paths, it won’t match.

❌ Example of what breaks:
tsx
Copy
Edit
<Route path="/dashboard" component={Dashboard} />
This won’t work inside /es-pe/* because Wouter thinks you're still matching /dashboard, not /es-pe/dashboard.

✅ Here's Exactly What You Need to Do:
🔧 Step 1: Confirm Top-Level Route Looks Like This
In App.tsx:

tsx
Copy
Edit
<Route path="/:lang/*" component={<LanguageGuard />} />
🔧 Step 2: Fix LanguageGuard.tsx (Core Language Handling)
tsx
Copy
Edit
import { useEffect } from 'react';
import { useParams, useLocation } from 'wouter';
import { Navigate } from 'wouter';
import i18n from '@/i18n/i18n';

const SUPPORTED_LANGUAGES = ['en-us', 'es-pe', 'sk-sk'];

export function LanguageGuard() {
  const [params] = useParams();
  const { lang } = params;
  const [location] = useLocation();

  useEffect(() => {
    if (SUPPORTED_LANGUAGES.includes(lang)) {
      i18n.changeLanguage(lang);
    }
  }, [lang]);

  // Redirect invalid lang to /en-us
  if (!SUPPORTED_LANGUAGES.includes(lang)) {
    return <Navigate to="/en-us/dashboard" />;
  }

  // Strip the lang and pass the remaining route to AuthenticatedApp
  const strippedPath = location.replace(`/${lang}`, '') || '/dashboard';

  return <AuthenticatedApp basePath={`/${lang}`} subPath={strippedPath} />;
}
🔧 Step 3: Fix AuthenticatedApp.tsx to Use Relative Paths
Inside AuthenticatedApp, you must not use absolute routes. Instead:

tsx
Copy
Edit
import { Route, Switch } from 'wouter';

export default function AuthenticatedApp({ basePath, subPath }) {
  return (
    <Switch>
      <Route path="/dashboard" component={Dashboard} />
      <Route path="/transactions" component={Transactions} />
      <Route path="/income" component={Income} />
      {/* etc */}
    </Switch>
  );
}
If this still doesn't work, try switching to using useRoute from Wouter or even simplifying with:

tsx
Copy
Edit
<Router base={basePath}>
  <Route path="/dashboard" component={Dashboard} />
  ...
</Router>
This tells Wouter to treat all routing inside this Router relative to /${lang}.
